# Домашнее задание 1 – Python: основы (Занятие 1)

Задание закрывает материал первого занятия: как исполняется программа
и что происходит при `x = 7`, разделяемые ссылки и копирование,
`==` против `is`, изменяемые и неизменяемые объекты, числовые типы
(`int`, `float`, `complex`, `bool`, `Fraction`, `Decimal`), создание
чисел и арифметика.

## Что нужно сделать

Откройте [`hw01.py`](hw01.py) и реализуйте **10 функций**. Каждая
функция сейчас состоит из docstring-описания (с примерами
input/output) и строки `raise NotImplementedError` – замените её
своим кодом.

**Нельзя:**
- менять имена функций и их параметры;
- удалять или переименовывать функции;
- использовать сторонние библиотеки (только стандартная библиотека
  Python – `cmath`, `copy`, `fractions`, `decimal` уже импортированы
  в файле, этого достаточно для всех заданий).

## Список заданий

| № | Функция | Тема |
|---|---|---|
| 1 | `add_to_log` | ловушка изменяемого аргумента по умолчанию |
| 2 | `exact_sum` | точная арифметика с `Fraction` |
| 3 | `round_money` | денежное округление с `Decimal` |
| 4 | `active_flags` | побитовые операции |
| 5 | `independent_copy` | `copy.deepcopy` и разделяемые ссылки |
| 6 | `complex_magnitudes` | комплексные числа |
| 7 | `count_passing` | `bool` как подкласс `int` |
| 8 | `to_all_bases` | `bin` / `hex` / `oct` |
| 9 | `floor_and_truncated_division` | `//` и деление с отрицательными числами |
| 10 | `filter_out_none` | `is` против `==` (ловушка `AlwaysEqual`) |

Подробное описание каждой функции, включая примеры input/output –
в её docstring внутри `hw01.py`.

## Как проверить себя локально

Из корня репозитория:

```bash
pip install -r requirements.txt
pytest tests/hw01 -v
```

Все тесты должны быть зелёными (`passed`), прежде чем вы отправите
решение – именно эти тесты запустит GitHub Actions при `git push`.

## Как сдать

Закоммитьте изменения **только в файле `hw01.py`** и запушьте их в
**свой** репозиторий (тот, что вы создали через **Use this
template** – см. корневой `README.md`). Через 1–2 минуты после push
откройте вкладку **Actions** в своём репозитории на GitHub – там
будет виден результат автоматической проверки и сводная таблица по
каждому тесту.

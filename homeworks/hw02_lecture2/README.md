# Домашнее задание 2 – Python: основы (Занятие 2)

Задание закрывает материал второго занятия: строки и форматирование,
коллекции (список, кортеж, словарь, множество), файлы и сериализация
(`json`, `csv`), ветвления, циклы и протокол итерации.

## Что нужно сделать

Откройте [`hw02.py`](hw02.py) и реализуйте **10 задач** (11 функций –
задание 5 состоит из двух связанных функций). Каждая функция сейчас
состоит из docstring-описания (с примерами input/output) и строки
`raise NotImplementedError` – замените её своим кодом.

**Нельзя:**
- менять имена функций и их параметры;
- удалять или переименовывать функции;
- использовать сторонние библиотеки (только стандартная библиотека
  Python – `csv`, `json`, `string` уже импортированы в файле, этого
  достаточно для всех заданий);
- обходить проверку в задании 8 обёртками/трюками – там явно
  проверяется, что диспетчеризация сделана через словарь, а не через
  `elif`.

## Список заданий

| № | Функция | Тема |
|---|---|---|
| 1 | `format_report` | форматирование f-строками |
| 2 | `normalize_tokens` | методы строк, дедупликация с сохранением порядка |
| 3 | `top_k` | `sorted`, `key`, `reverse` |
| 4 | `group_by_length` | `setdefault` / `defaultdict` |
| 5 | `word_frequencies`, `common_words` | словари и множества |
| 6 | `save_and_load_json` | файлы и сериализация JSON |
| 7 | `write_read_csv` | файлы и сериализация CSV |
| 8 | `calculate` | словарь функций вместо `if/elif` |
| 9 | `moving_average` | циклы без `numpy` |
| 10 | `first_n_odd` | протокол итерации: `iter`/`next`/`StopIteration` |

Подробное описание каждой функции, включая примеры input/output –
в её docstring внутри `hw02.py`.

## Как проверить себя локально

Из корня репозитория:

```bash
pip install -r requirements.txt
pytest tests/hw02 -v
```

Все тесты должны быть зелёными (`passed`), прежде чем вы отправите
решение – именно эти тесты запустит GitHub Actions при `git push`.

## Как сдать

Закоммитьте изменения **только в файле `hw02.py`** и запушьте их в
**свой** репозиторий (тот, что вы создали через **Use this
template** – см. корневой `README.md`). Через 1–2 минуты после push
откройте вкладку **Actions** в своём репозитории на GitHub – там
будет виден результат автоматической проверки и сводная таблица по
каждому тесту.
